# S6: Selective MIMO State Space Model

## Overview

S6 combines the best ideas from S4D, S5, and Mamba into a single SSM layer designed to slot into the ripple mixer architecture (where local context is already handled by multi-scale convolution).

**Base implementation:** S4D (`s4/models/s4/s4d.py`) — we copy and make targeted edits, not a rewrite.

## What We Take From Each

| Source | What | Why |
|--------|------|-----|
| **S4D** | Base code, HiPPO-LegS A initialization, complex diagonal state | Proven init, clean impl |
| **S5** | Dense B (P,H) and C (H,P) — MIMO cross-channel mixing | Cross-feature state mixing without full matrix A |
| **Mamba** | Input-dependent dt projected from input | Selectivity — content-based gating of state updates |
| **Ours** | SiLU activation (no GELU), no GLU post-processing, no local conv | Ripple's msconv handles local; SiLU matches our attention stage |

## Feature Banks on B/C (from LUNA)

SSMs tend to drown in their own noise over long sequences — the state accumulates everything indiscriminately. LUNA-style feature banks on the B and C projections give the SSM learned selectivity over what to integrate and what to read out.

Instead of linear B/C projections:
```
# Before (dense linear):
Bu = B @ u                    # projects everything into state

# After (feature bank):
Bu = phi_B(u)                 # learned nonlinear projection selects what enters state
y  = phi_C(h)                 # learned nonlinear projection selects what to read out
```

Each feature bank is a `LearnableFeatureMap` (from `zoology/zoology/mixers/luna.py`):
- M projection directions with learned weights
- Shared channel MLP: scalar → L channels
- Output dim D = M * L maps to state dimension P

**B feature bank:** `phi_B: H → P` — learns what input features to integrate into state
**C feature bank:** `phi_C: P → H` — learns what state features to read out

The feature banks add a modest parameter cost (M directions × MLP params) but give the SSM content-dependent filtering that dense linear projections cannot provide. The channel MLP's nonlinearity means the bank can learn to suppress noise patterns while amplifying signal.

## What We Remove From S4D

1. **FFT convolution** — replaced by parallel scan (Triton kernel). Input-dependent dt breaks LTI, so no convolution mode.
2. **GELU + Conv1d(H→2H) + GLU output** — replaced by SiLU. The GLU channel mixing is unnecessary because MIMO B/C already mix channels.
3. **Per-channel SISO structure** — replaced by shared MIMO state.
4. **`DropoutNd`** — use standard dropout or none.

## Architecture

### Parameters

```
A:          (P,) complex diagonal     — HiPPO-LegS eigenvalues (from S4D/S5 init)
phi_B:      LearnableFeatureMap(H→P)  — feature bank input projection (LUNA-style)
phi_C:      LearnableFeatureMap(P→H)  — feature bank output projection (LUNA-style)
D:          (H,) real                 — skip connection
dt_proj:    nn.Linear(H, P)          — input-dependent timestep, SiLU activated
log_dt_bias: (P,) real               — bias for dt, init in [log(dt_min), log(dt_max)]
lambda_proj: nn.Linear(H, P)         — trapezoidal interpolation weight, sigmoid activated
theta_proj: nn.Linear(H, P//2)       — data-dependent RoPE frequencies
b_norm:     RMSNorm(P)               — learnable RMSNorm on B projection (QK-norm style)
c_norm:     RMSNorm(P)               — learnable RMSNorm on C projection (QK-norm style)
b_bias:     (P,) real, init=1.0      — additive bias on B after norm (Mamba-3: critical w/ trapezoidal)
c_bias:     (P,) real, init=1.0      — additive bias on C after norm (Mamba-3: critical w/ trapezoidal)
```

Where:
- H = d_model (input/output dimension)
- P = d_state (state dimension, e.g. 64)

### Discretization: Learned Trapezoidal

Based on our existing TrapSSM implementation (`src/heuristic_secrets/models/backbone.py:1495`). Instead of fixed bilinear transform, we use a **learned, input-dependent interpolation** between forward and backward Euler:

```
dt     = softplus(silu(dt_proj(u)) + log_dt_bias)   # (B, L, P) input-dependent
lam    = sigmoid(lambda_proj(u))                      # (B, L, P) interpolation weight
alpha  = exp(dt * A)                                  # (B, L, P) decay factor
beta   = (1 - lam) * dt * alpha                       # weight on PREVIOUS injection (lookback)
gamma  = lam * dt                                      # weight on CURRENT injection
```

State update uses both current and previous B*u:
```
Bu     = phi_B(u)                                     # feature bank projection
Bu_prev = pad(Bu[:-1], left=1)                        # shifted by 1
inject = gamma * Bu + beta * Bu_prev                  # trapezoidal blend
h[t]   = alpha[t] * h[t-1] + inject[t]               # state update via parallel scan
```

Lambda init: `sigmoid(2.0) ≈ 0.88`, biased toward forward Euler (current input). The model learns to look back more where needed.

### Data-Dependent RoPE on B/C

Following our TrapSSM pattern (`backbone.py:1485-1491`):
```
theta     = theta_proj(u)                             # (B, L, P//2) per position
delta_theta = dt * theta                              # scale by timestep
cum_theta = cumsum(delta_theta, dim=1)                # cumulative rotation
B_proj    = apply_rotary_emb(B_proj, cum_theta)       # rotate B in state space
C_proj    = apply_rotary_emb(C_proj, cum_theta)       # rotate C in state space
```

This gives the SSM data-dependent frequency modulation — positions with larger dt rotate faster through state space.

### Forward Pass: Parallel Scan

```
Input: u (B, L, H)

1. Projections (all SiLU-activated):
   dt    = softplus(silu(dt_proj(u)) + log_dt_bias)  # (B, L, P)
   lam   = sigmoid(lambda_proj(u))                    # (B, L, P)
   theta = theta_proj(u)                              # (B, L, P//2)

2. Feature bank projections + norms + biases:
   Bu    = b_norm(phi_B(u)) + b_bias                  # (B, L, P) — learned what to write
   Bu_prev = pad(Bu[:, :-1], left=1)                  # (B, L, P) — shifted

3. Data-dependent RoPE:
   cum_theta = cumsum(dt * theta, dim=1)              # (B, L, P//2)
   Bu    = apply_rotary(Bu, cum_theta)
   # C rotation applied at readout

4. Trapezoidal discretization:
   alpha  = exp(dt * A)                               # (B, L, P) decay
   inject = lam*dt * Bu + (1-lam)*dt*alpha * Bu_prev  # trapezoidal blend

5. Parallel scan (Triton kernel):
   h[t] = alpha[t] * h[t-1] + inject[t]              # elementwise (diagonal A)
   Returns all h[t]: (B, L, P)

6. Readout via feature bank:
   C_rot = apply_rotary(phi_C_weight, cum_theta)      # rotate C
   y = (c_norm(einsum(C_rot, h)) + c_bias).real        # (B, L, H)
   y = y + D * u                                       # skip connection

7. Activation:
   y = silu(y)
### Projection Activations & Norms

All projections (B, C, dt_proj) are SiLU-activated, matching our CausalSelfAttention pattern where QKV projections go through `self.act(self.qkv(x))`.

```
B_proj = silu(B @ u)           # activated before entering state
C_proj = silu(C @ h)           # activated before readout  
dt     = softplus(silu(dt_proj(u)) + log_dt_bias)
```

Learnable RMSNorm (QK-norm style) on B and C projections:
```
B_proj = b_norm(B_proj)        # RMSNorm on input projection, per state dim
C_proj = c_norm(C_proj)        # RMSNorm on readout projection, per state dim
```

This prevents magnitude drift in the state space and stabilizes training, same reason QK-norm helps attention.

**BC biases** (init=1.0, learnable, added after norm): From Mamba-3 — these synergize with trapezoidal discretization and **eliminate the need for a short conv** before the SSM. Without biases, trapezoidal discretization underperforms Euler. With biases, it strictly dominates. Our TrapSSM in `backbone.py` already has `b_bias` and `c_bias` for this reason.
```

### Triton Kernel: Parallel Associative Scan

The scan is the bottleneck. Python sequential is O(L) with no parallelism. We need a Triton kernel implementing the associative scan with the binary operator:

```
(a_i, b_i) ⊕ (a_j, b_j) = (a_j * a_i, a_j * b_i + b_j)
```

Where a = A_bar (complex diagonal) and b = Bu (complex). All operations are elementwise since A is diagonal.

**Kernel structure:**
- One program per (batch, state_dim) pair
- Each program scans over L positions
- Up-sweep (reduce) + down-sweep (propagate) pattern
- Complex arithmetic throughout (store as float2 or pair of floats)
- Support variable A_bar per position (input-dependent dt means A_bar varies)

### Specific Edits to s4d.py → s6.py

#### S4DKernel → S6Kernel

1. **Remove** `forward(L)` Vandermonde/FFT kernel generation entirely
2. **Replace** dense B/C with `LearnableFeatureMap` feature banks (phi_B: H→P, phi_C: P→H)
3. **Change** A init from S4D-Lin to HiPPO-LegS eigenvalues (via `make_DPLR_HiPPO`)
4. **Add** `dt_proj = nn.Linear(H, P)` for input-dependent dt, SiLU activated
5. **Add** `log_dt_bias` parameter `(P,)`, init uniform in [log(dt_min), log(dt_max)]
6. **Add** `lambda_proj = nn.Linear(H, P)` for trapezoidal interpolation, sigmoid, init bias=2.0
7. **Add** `theta_proj = nn.Linear(H, P//2)` for data-dependent RoPE, init zeros
8. **Add** `b_norm = RMSNorm(P)`, `c_norm = RMSNorm(P)` — learnable norms on B/C projections
8b. **Add** `b_bias = nn.Parameter(torch.ones(P))`, `c_bias = nn.Parameter(torch.ones(P))` — additive biases after norm (Mamba-3)
9. **Add** `forward(u)` method: project → feature bank → RoPE → trapezoidal discretize → scan → readout

#### S4D → S6

1. **Remove** FFT convolution in forward
2. **Remove** `output_linear` (Conv1d + GLU)
3. **Change** activation from GELU to SiLU
4. **Remove** DropoutNd
5. **Forward** becomes: `kernel.forward(u)` → skip connection → SiLU → optional out_proj
